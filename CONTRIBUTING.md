# Contributing

Thanks for helping improve Kuching Air Reader.

1. Fork the repository and create a focused branch.
2. Run `npm install`, then `npm test` before submitting a pull request.
3. Keep provider parsing changes covered by a small HTML fixture test.
4. Do not commit API tokens, cookies, scraped personal data, or generated build output.

Provider markup can change without notice. Please include the source URL and the date a parser fix was verified.
